PROPOSAL A inventory management application designed for summer house owners. The idea/goal is to maintain a real-time log of supplies, tools and consumables available at the property. It makes it easier for people to come visit the house without having to wonder what needs to be bought.

CORE FEATURES and FUNCTIONALITY

Location-based inventory browser: Browse items grouped by location in the house (Kitchen, Bathroom, Toolshed...)

Stock level & unit management: Track precise quantities (amount of toilettpaper, x liters of water...)

Low stock alert system: Set custom threshold values (minimum quantity) per item. LOW_STOCK or OUT_OF_STOCK

Interactive Quantity Adjuster: Increment/decrement stock with a single click action without needing to edit a form.
